## Status Legend

- **draft** — In backlog, not ready for implementation
- **approved** — In backlog, ready (use `/focus {category}/{slug}`)
- **in-progress** — Being implemented (at least one track started, not all done)
- **testing** — Implemented, automated tests pass; awaiting user end-to-end confirmation
- **done** — Completed across all tracks, permanent reference (user-confirmed)
- **cancelled** — Abandoned, kept for context

Per-track status (in each folder's Tracks table): `not-started | in-progress | testing | done | cancelled`.
